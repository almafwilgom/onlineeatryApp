# Online Eatery 🍽️

**PORA Tech Academy — Full-Stack Capstone Project**

A full-stack food ordering and management system built with React, Node.js, Express, and MongoDB.

---

## Quick Start (Development)

### Prerequisites
- Node.js v18+
- npm v9+
- MongoDB Atlas account

### Backend
```bash
cd backend
cp .env.example .env
# Fill in your values in .env
npm install
npm run dev
```

### Frontend
```bash
cd frontend
cp .env.example .env
# Fill in your values in .env
npm install
npm run dev
```

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React + Vite + Tailwind CSS |
| Backend | Node.js + Express |
| Database | MongoDB Atlas + Mongoose |
| Auth | JWT + bcryptjs |
